5. TRAINING FROZEN RAW (contoh tahap pertama):
   python 04_train_frozen_5fold_e6.py --fold 1 --variant raw
   python 04_train_frozen_5fold_e6.py --fold 2 --variant raw
   python 04_train_frozen_5fold_e6.py --fold 3 --variant raw
   python 04_train_frozen_5fold_e6.py --fold 4 --variant raw
   python 04_train_frozen_5fold_e6.py --fold 5 --variant raw

   Ganti '--variant raw' dengan '--variant clahe' untuk Frozen CLAHE.
   Gunakan 04_train_lora_5fold_e6.py pada --fold 1..5 untuk LoRA RAW/CLAHE.
   Jangan menjalankan dua proses GPU training secara paralel pada VRAM 6 GB.

6. KONFIGURASI (identik dengan E5, kecuali CV):
   Frozen head: batch=64; gradient accumulation=1; AdamW head LR=0.001.
   LoRA: micro batch=1; gradient accumulation=16 (effective 16);
         LoRA LR=0.0001; head LR=0.001; r=8; alpha=16; dropout=0.05;
         blocks 9-12 (zero-based 8-11) query/value.
   Cross Entropy; weight decay=0.0001; 30 epochs; patience=5;
   minimum AUROC improvement=0.001; seed=42; threshold=0.5.
   Checkpoint terbaik dipilih dari masing-masing fold validation AUROC.
   AMP FP16 khusus LoRA. Test E5 sama sekali TIDAK dibaca saat training.

   eksperimen6\output\training\frozen_raw_fold_1\
