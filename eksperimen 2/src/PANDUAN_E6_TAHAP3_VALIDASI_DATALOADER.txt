1. EKSTRAK
Simpan 03_validasi_dataloader_eksperimen6.py di:
RAD-DINO-TB\eksperimen6\src\

RAD-DINO-TB\eksperimen5\

2. PERIKSA INPUT (tidak membuka piksel citra)
(tb-env) > python 03_validasi_dataloader_eksperimen6.py --check

Keluaran diharapkan:
DRY CHECK PASS_E6_DATALOADER_LOCKS

3. PERIKSA DATALOADER (memuat sejumlah batch TRAIN/VAL untuk semua fold)
(tb-env) > python 03_validasi_dataloader_eksperimen6.py --run --batch-size 4 --batches 2

Jika processor RAD-DINO telah tersimpan dalam cache lokal dan internet tidak digunakan:
(tb-env) > python 03_validasi_dataloader_eksperimen6.py --run --batch-size 4 --batches 2 --offline-processor

Perintah --run akan memeriksa semua kombinasi:
  5 fold x 2 subset (train, validation) x 2 varian (RAW, CLAHE) = 20 kombinasi
  2 batch x 4 citra untuk setiap kombinasi

Batch 4 hanya untuk AUDIT DATALOADER, BUKAN batch training.
Training hyperparameter tetap mengikuti protokol E5:
  Frozen: classifier head batch 64, accumulation 1
  LoRA: physical batch 1, gradient accumulation 16
